# Structure-Preserving Representation for Underwater Visibility Enhancement under Degraded Acquisition Conditions

This repository contains the MATLAB implementation of the proposed underwater image enhancement framework using Single-Scale Retinex (SSR), Laplacian pyramid decomposition, iterative Gaussian sharpening, and Weighted Local Energy (WLE) adaptive fusion.

## Requirements
- MATLAB 
- Image Processing Toolbox

## Usage
Run `main.m` to process the sample images.
